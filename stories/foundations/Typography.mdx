# 🔤 Typography

Three font-family stacks, each with one job — exposed as `--font-*` aliases over the
`--mind-font-*` primitives. A brand can swap any stack; everything else inherits the defaults.

- **Serif** (Fraunces) — **headlines**. The base layer sets `h1`–`h3` in the serif automatically.
- **Sans** (Hanken Grotesk) — **the default** for body copy, UI chrome, and small structural
  headings (`h4`–`h6`).
- **Mono** (JetBrains Mono) — **code and technical labels** only: code blocks, `kbd` keys,
  tokens, and eyebrows. Never running prose.

Each specimen renders with its live CSS variable, so **changing brand in the toolbar**
re-paints the page with that brand's chosen stack.

## 📐 The type scale

The scale across the steps a brand composes with — from a `text-5xl` display down to a
`text-xs` caption. **Display, Title, and Heading map to `h1`–`h3` and carry the serif**;
everything from Subheading down is sans — the same split the base layer applies to real
headings.

## 🧭 Sans for the interface

Most product text is **sans** — glanceable, dense, legible at small sizes and tight
line-heights. Here it carries a heading, body copy, a definition list, and small print without
breaking stride.

<Canvas of={TypographyStories.Interface} />

## 💻 Mono for code & technical labels

The **mono** stack is for when alignment or technical precision is the message — code blocks,
tabular figures, keyboard keys (`kbd`), and short technical labels. Code, `kbd`, `pre`, and
`samp` already resolve to it automatically; reach for `font-mono` for the rest. Keep it off
running prose and form labels.
