# ✨ Icons

The complete [`lucide-react`](https://lucide.dev) icon set, imported from lucide's own registry
so this gallery always reflects exactly the icons the package ships. Every icon inherits
`currentColor`, so it picks up the active theme's foreground in both light and dark mode.

🔎 **Search** by name or keyword — synonyms like `trash` find `Trash2`, `home` finds `House`.
🏷️ **Filter** by any of lucide's categories; pick several to broaden the results.
📋 **Click** any icon to copy its ready-to-paste import statement.

Import any icon by name:

```tsx
import { ArrowRight } from "lucide-react";

<ArrowRight className="size-5" />;
```
