# 🌱 Avatars

A small set of **reference-only** placeholder portraits **for mocking** user
lists, comment threads, account menus, and presence UI. Every tile links to a
CDN URL — **no binary assets ship in this package**.

> 🧪 **Placeholder faces.** These are free [pravatar.cc](https://i.pravatar.cc)
> stand-in faces, not Mind people or a licensed avatar set. They exist so
> prototypes look real; the curated Mind set will replace them in a single
> `_assets.ts` edit. **Do not ship these to production.**
