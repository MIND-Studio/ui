# M0 — Skeleton ✅

**Goal:** stand up the package, the two-layer token system, the typed theme, the provider, and
one component rendering live across all brands × modes — the end-to-end pipeline in miniature.

## Delivered

- **Package + tooling** — `@mind-studio/ui`, ESM, `exports` map (`.`, `./themes`, `./styles.css`),
  peer deps (`react`/`react-dom`/`next`/`tailwindcss`), `sideEffects: ["*.css"]`. bunchee build,
  strict `tsconfig`, Vitest (happy-dom), Storybook 9 (`@storybook/nextjs-vite`), `components.json`.
- **Two token layers**
  - `src/tokens/base.ts` — `--mind-*` primitives (neutral OKLCH grayscale ramp, radius, fonts).
  - `src/tokens/aliases.ts` — semantic tokens using **shadcn's exact variable names** + the
    contrast-pair manifest.
- **Typed `Theme`** — `src/theme/schema.ts`, Zod-validated, all 7 axes, explicit light/dark with
  base fallback. `parseTheme` + `toDataUrl` helpers.
- **Serialization** — `src/theme/serialize.ts`: one serializer shared by the static-CSS generator,
  the runtime injector, and the contrast resolver. Emits `:root`/`.dark`, the Tailwind v4
  `@theme inline` mapping, and scoped `[data-mind-theme]` rules (both modes).
- **Provider** — `src/theme/provider.tsx`: `<ThemeProvider>` wraps `next-themes`
  (`attribute="class"`), sets `[data-mind-theme]`, injects scoped CSS. `useMindTheme()` hook.
- **Mind default theme** — `src/themes/mind.ts` (complete alias maps) → static `styles.css`
  generated by `scripts/gen-styles.ts`.
- **First component** — `src/components/button.tsx`, pristine shadcn (only the `cn` import path
  changed), re-exported from the barrel; `Button.stories.tsx`.
- **Storybook** — brand & mode toolbar globals + `<ThemeProvider>` decorator.
- **`CLAUDE.md`** — written last, documenting the real structure + conventions.

## Definition of Done — verified

- `pnpm build` + `pnpm typecheck` green; `"use client"` preserved in the provider chunk.
- Button renders in Storybook switchable across Mind + Ember + Arctic × light/dark.

## Decisions made here

- **CSS is generated from the typed tokens** (not hand-written) so the static stylesheet can't
  drift — `styles.css` is gitignored and regenerated by `prebuild`/`prestorybook`.
- **`b1aKNEsKI` preset wasn't available as a file** → base seeded from a standard neutral OKLCH
  ramp + a Mind indigo; values are tunable and validated by the contrast gate.
- Resolved a local pnpm `allowBuilds` gate (native build-script approval) via
  `pnpm-workspace.yaml` + `.npmrc`.
